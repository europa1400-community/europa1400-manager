# Europa 1400 Manager

Install community patches and fixes for **Europa 1400: The Guild** (*Die Gilde*) with a few clicks: graphics fixes for
modern Windows, the multiplayer network fix and more. The manager detects your game version and only offers what fits.

[Download for Windows](https://github.com/europa1400-community/europa1400-manager/releases/latest/download/europa1400-manager-gui-windows.exe){ .md-button .md-button--primary }
[All downloads](getting-started.md#download){ .md-button }

## What it does

- **Detects your game**: edition, version, language and store (GOG, Steam, CD).
- **Installs patches**: downloads them from their official sources and puts them into the game folder; patches a
  patch depends on come along automatically.
- **Removes them again**: uninstalling deletes the patch's files (the patch loader also restores its `game.ini`
  setting).
- **Starts the game**, normal or the T&L version.

Patches and game versions are kept in the
[Europa 1400 Database](https://europa1400-community.github.io/europa1400-database/), so new patches show up without
updating the manager.
